# Hex++

VS Code 十六进制查看 / 编辑 / 对比扩展，支持 BIN、Intel HEX、S-Record、TI-TXT、ELF。

## 快速上手

| 想做什么 | 怎么做 |
| --- | --- |
| 打开文件 | 资源管理器右键 **Open in Hex++**（`.bin/.hex/.srec/.elf` 等任意文件） |
| 按 1 / 2 / 4 字节显示 | 工具栏 `1 2 4`，或 `Ctrl+1 / Ctrl+2 / Ctrl+4`；`小端 LE` 按钮切换字节序 |
| 跳转 | `Ctrl+G` 或工具栏 Go To：`0800_1000`、`0x1000`（十六进制），`#4096`（十进制），`+10`（相对） |
| 编辑 | `Insert` 切换只读/读写，直接输入十六进制；`Tab` 切到 ASCII 区；`Ctrl+Z/Y` 撤销/重做 |
| 复制 | `Ctrl+C` 按当前显示复制（随 1/2/4 字节单元）；`Ctrl+Alt+C` 选格式（带预览，最近用过的排第一） |
| 另存为 / 格式互转 | 工具栏 **另存为…** 或右键 **Save As / Convert Format...**，BIN→HEX 时会询问起始地址 |
| 对比 | 资源管理器选中两个文件右键 **Compare Selected (Hex++)**，或在编辑器中点 **比较…** |

## 对比视图

工具栏：`全部` / `差异`（只看差异，相同的大块区域折叠）、`下一个`(F8) / `上一个`(Shift+F8)、`交换`、`重载`(F5)、`导出报告`。左侧红条为差异概览，点击可跳转。

## 开发

```bash
npm install
npm test          # 编译并运行单元测试
```

按 F5（Run Hex++）启动扩展开发宿主。
